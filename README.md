# SPACE INVADERS 3D

レトロな「スペースインベーダー」を 3D で再現した、単一 HTML ファイルのブラウザゲームです。
外部ライブラリや外部リソースは一切使わず、生の WebGL と Web Audio だけで動くため、
オフラインでも `index3.html` を開くだけで遊べます。

## 特徴

- **視点切替**: 正面 / 俯瞰 / 斜め / 周回 / 追尾 の 5 モード
- インベーダーは原作と同じ 8x8 / 11x8 / 12x8 のドット絵(シルエット押し出しで立体化)
- バンカー(トーチカ)は原作と同じ形で、弾が当たると削れて穴が開く
- 自弾と敵弾は撃ち合うと相殺する
- UFO の得点は原作 ROM のテーブル(100 / 50 / 150 / 300 点、15 発周期で 23 発目が 300 点)
- ウェーブクリア演出、飛来演出、スコアポップ、放置時の自動プレイ(アトラクトモード)
- 最後の 1 匹になると 3 倍速で移動

## 操作方法

### キーボード

| キー | 動作 |
| --- | --- |
| ← → | 移動 |
| SPACE / Enter | 発射・スタート |
| P | ポーズ |
| V / 1-5 | 視点切替 |
| M | ミュート |
| ESC | タイトルへ戻る |

### スマートフォン(タッチ)

画面下のパッドを使用します。

| ボタン | 動作 |
| --- | --- |
| ◀ ▶ | 移動 |
| FIRE | 発射 |
| CAM | 視点切替 |
| II | ポーズ |

画面タップでも発射・スタートできます。ゲーム画面のドラッグで周回ビュー、
ピンチズームやダブルタップ拡大は無効化しています(対応端末ではボタンが左右に分かれます)。

## 実行

`index3.html` をブラウザで開くだけです。ローカルファイル(`file://`)でも動作し、サーバは不要です。
